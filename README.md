# Фото → 3D прогулка (photo-walk-3d)

Загрузите **любое фото** (комната, улица, предмет, пейзаж…) — в браузере запускается оценка глубины (Transformers.js + Depth Anything small), строится текстурированный меш на Three.js, и можно ходить от первого лица (WASD + мышь / тач).

> ⚠️ Одно фото даёт **приближённый** 3D, это не LiDAR и не полноценная реконструкция. Качество зависит от фото.

## Стек

- Vite + vanilla JS
- Three.js (`PointerLockControls`, WASD, тач-джойстик)
- `@xenova/transformers` — depth-estimation in-browser (без API-ключей)

## Запуск

```bash
npm i
npm run dev
```

Откройте URL из терминала (обычно http://localhost:5173).

Сборка:

```bash
npm run build
npm run preview
```

## Управление

| Платформа | Смотреть | Ходить |
|-----------|----------|--------|
| Desktop   | Клик по сцене → мышь (Esc — отпустить) | WASD / стрелки |
| Mobile    | Палец справа | Джойстик слева |

Кнопки: **⌂** — сброс позиции, **Новое фото** — загрузить другое изображение.

## Как это работает

1. Фото масштабируется для инференса (~512px) и прогоняется через Depth Anything.
2. Карта глубины смещает вершины плоскости; исходное фото — текстура (UV совпадают).
3. Камера ставится «перед» сценой; простая фиксация высоты глаз (y clamp).

Модель скачивается в браузер при первом запуске (кэшируется). Нужен интернет и WebGPU/WASM.

Во время обработки видны спиннер, шаги (Загрузка → Модель → Глубина → 3D) и полоса прогресса.
